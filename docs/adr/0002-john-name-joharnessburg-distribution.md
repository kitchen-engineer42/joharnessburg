# The plugin is named `john`; the marketplace/repo stays `joharnessburg`

Two names, on purpose: `john` is the call sign (short to type, friendly commands — `/john:*`, `claude plugin install john@joharnessburg`), while `joharnessburg` is the distribution identity because "john" is taken as a name nearly everywhere, joharnessburg is unique, and the pun carries "harness" into search. Don't "fix" the split by renaming either side — the divergence is the decision.
